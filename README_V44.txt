- Contact

- Buyer Portal dashboard

- Admin shell gets visual normalization only (no operational restructure)

CORE DESIGN MOVES
- DM Sans remains the UI typeface.
- Real Pharma Service logo remains everywhere.
- High-quality composition is driven by hierarchy, procurement objects, tactile surfaces, whitespace and purposeful asymmetry.
- Search is moved ahead of category browsing on the public catalogue.
- Buyer portal cards are reduced and replaced where possible with ledgers / structured activity.
- Portal home gets asymmetric action composition and an operational strip.
- Orders become horizontal procurement records rather than generic dashboard cards.
- Workshop becomes editorial / magazine-like.
- Home hero becomes an institutional requirement object instead of a decorative hero illustration.
- Contact and RFQ forms are treated as professional intake documents.
- Motion is limited to key objects and calm reveals; no universal card jumping.

- Catalogue data is untouched.
- Product-family logic is untouched.
- Quote/order/replenishment actions are untouched.
- Portal/admin routing is untouched.
- Existing V39 fixes remain.
- V43 Our Model remains the approved page and is not overwritten.
